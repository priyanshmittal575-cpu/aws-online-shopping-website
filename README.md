# Online Shopping Website

Full-stack campus tech store with product search, category filtering, quantity-managed cart, and persistent backend orders.

## Features & Overview
- Built as part of the **B.Tech 1st Year Web Designing & Full-Stack Development** project series.
- Clean, modular separation of markup, styling, client-side logic, and backend/database schemas.

## Tech Stack
- Node.js, HTML5, CSS3, Vanilla JavaScript, SQL Schema

## How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/priyanshmittal575-cpu/aws-online-shopping-website.git
   cd aws-online-shopping-website
   ```
1. Ensure **Node.js** is installed.
2. Start the server:
   ```bash
   node server.js
   ```
3. Open the `localhost` URL printed in the terminal.
